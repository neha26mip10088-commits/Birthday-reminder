🎂 Birthday Reminder System

About the Project

Birthday Reminder System is a simple Python project made to keep track of a user's birthday. The program takes the name and birthday from the user and checks whether the birthday is today or not.

The program takes the details only once and stops automatically after showing the result.

Objective

The main purpose of this project is to:

- Check the user's birthday.
- Show a birthday wish if the birthday is today.
- Calculate how many days are left for the next birthday.
- Practice basic Python programming.

Technology Used

- Python 3
- "datetime" module

How It Works

1. The program asks for the user's name.
2. It asks for the birthday in "DD-MM-YYYY" format.
3. It checks the current date.
4. If the birthday is today, it shows a birthday message.
5. If it is not today, it calculates the remaining days.
6. The result is displayed on the screen.
7. The program stops automatically.

How to Run

1. Install Python 3.
2. Open the Python file.
3. Run the program.
4. Enter your name and birthday when asked.

Example:

Enter your name: Neha
Enter your birthday (DD-MM-YYYY): 30-09-2006

Sample Output

Name: Neha
Birthday: 30-09-2006

Your birthday is not today.
Days left: 3
Next Birthday: 30-09-2026

PROGRAM STOPPED SUCCESSFULLY
